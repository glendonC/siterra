# Show comparable places as context by analogy, never as evidence about the case

## Context and Problem Statement

Showing other places where similar institutions or interventions were studied could help a user judge options. Restoration practice builds reference models from comparable sites, but comparing with a reference does not show cause, and adjacent valleys differ through several co-varying factors ([comparable places](../explanation/comparable-places.md)). How should Siterra present them?

## Considered Options

* Do not show comparable places
* Show them as published context by analogy with strict rules
* Use them as control sites for the case

## Decision Outcome

Chosen option: "published context by analogy with strict rules", because it answers a real decision question without overclaiming. Cards carry a study-design label, similarities, differences, required transfer limits and what the place cannot show; their numbers never leave the card; they cannot change a hypothesis status without case observations.

### Consequences

* Good, because the intervention comparison and field plan gain concrete precedents.
* Bad, because cards need careful writing and verified excerpts for every finding.

### Confirmation

Numeric provenance rejects analogue numbers in case-level statements; a claim rule blocks analogue-only status changes; P0 corpus sources produce evidence with "Analogy:" scope notes.
