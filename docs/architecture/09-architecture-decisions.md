# Architecture decisions

Architecture decisions are recorded once, as decision records in MADR 4.0.0 format in [`docs/decisions/`](../decisions/). The [decision log](../decisions/README.md) lists every record with its number, title and status; this section does not copy them.

Other arc42 sections cite decisions by ID (for example [ADR-0012](../decisions/0012-treat-the-case-record-as-authoritative.md) for the authoritative case record). A decision changes only through a new record that supersedes the old one; the old record stays readable with the status `superseded by ADR-NNNN`. How to write a record is in [CONTRIBUTING.md](../../CONTRIBUTING.md#documentation).
