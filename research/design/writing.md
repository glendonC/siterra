## Access notes

- ISO: HTTP 403 for both the fetch tool and curl; the national-store and catalog listings returned no text.
- iplfederation.org: the ISO page now serves unrelated content, so it was not used.
- Polaris: polaris.shopify.com redirects to shopify.dev, which no longer hosts the content guidelines; the archived repository files were used.
- Royal Society Open Science and PubMed blocked automated access; Europe PMC records (abstracts) were used.
- IPCC and ODNI PDFs were downloaded into isolated scratch folders and converted to text with pdftotext.
- Lint patterns were tested in Node 24.15 with a scratch harness (128 cases and 13 clean strings, 0 failures); the harness is not part of the deliverable.
